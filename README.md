# 羽球 3D 回放對照

選場館給你的 **3D 檔（`.badm3d`）** 和你拿到的**原始影片**：左邊 3D、右邊影片同步播放，3D 可以用手拖曳、縮放，從任何角度看整個球場，也能疊回影片上。

- 所有檔案只在你自己的裝置上讀取，**不會上傳到任何地方**（純靜態頁面，沒有後端）。
- 這個網站**只負責播放**，沒有分析、重建或判斷功能；3D 檔裡已經是算好的結果。
- 影片必須是製作 3D 檔時用的同一支檔案；不選影片也可以，只看 3D。
- 沒有場館提供的 `.badm3d`，這個網站沒有內容可看。

第三方：three.js r160（MIT，見 `vendor/three/LICENSE`）。
